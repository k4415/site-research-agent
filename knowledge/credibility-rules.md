# Credibility Rules

情報源の credibility 評価ルール。低い情報源は採用せず `excluded_sources` に理由付きで記載。

## Tier 評価

### Tier A（最優先採用）

- 政府統計（e-Stat、経産省、総務省）
- 第三者調査機関の公式レポート（矢野経済、Gartner、IDC、Statista）
- 上場企業の IR / 有報
- 学術論文（査読あり）

### Tier B（採用、出典明示）

- 信頼できるメディアの一次取材（日経、ITmedia、TechCrunch、ロイター）
- 業界トップ企業の公式ブログ・公式統計
- 公式アカウントによる X 投稿
- 検証可能な数値が含まれる Perplexity 出力

### Tier C（裏取りして採用）

- 業界中堅企業の公式コンテンツ
- 検証可能な数値を持つ調査会社（出典が辿れる）
- 業界カンファレンスの発表資料
- 個人専門家の X 投稿（フォロワー数 / 過去発言の整合性で評価）

### Tier D（採用しない）

- 出典不明の個人ブログ
- AI 生成記事（明示されているもの / フッタの "Powered by AI" 等）
- アフィリエイト記事（数値が誇張気味）
- 出典不明の「市場規模 〇〇億円」記事
- 5 年以上前の市場予測（古い）

## 数値の扱い

- 市場規模・成長率: 必ず 2 ソース以上で照合
- 「導入実績〇〇社」: 公式発表のみ採用、二次情報は出典記載
- 競合の数値主張: 「主張内容」として記録（事実とは分けて）

## 出典の書き方

事実レポート内では：

```markdown
- 国内デザインツール市場規模: 約540億円（2024年）
  - 出典: 矢野経済研究所「2024年版 デザインツール市場の現状と展望」
  - URL: https://...
  - 取得日: 2026-05-28
  - tier: A
  - 検証: 別ソース（Statista）でも同水準確認
```

## excluded_sources の記録

採用しなかった情報源を残す（後続判断の参考に）：

```yaml
excluded_sources:
  - url: https://example.com/blog
    reason: "出典不明の個人ブログ、数値が他のソースと大幅乖離"
    tier: D
    excluded_at: <ISO8601>
```
